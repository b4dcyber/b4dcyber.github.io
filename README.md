# B4DCYBER Portfolio

Responsive, dark cybersecurity-themed portfolio for Kashif Ahmed Siddiqui.

## Publish
This repository is named `b4dcyber.github.io`. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save. The site will be available at https://b4dcyber.github.io after GitHub Pages deployment completes.

## Safety
Review all biography, project, certification and experience details before sharing. Do not upload passwords, API keys, private client information, internal NRTC documents, or sensitive operational details.
