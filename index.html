PROJECT_01 · CONCEPT / ARCHITECTURE

B4DCYBER Sentinel — Wi-Fi & IoT Defence

A Zero-Trust security platform concept for protecting mixed networks containing agent-capable and agentless devices. The goal is to discover and classify devices such as IP cameras, printers, smart TVs and sensors, maintain a trusted-device inventory, identify suspicious network changes and help administrators respond.

Planned capabilities
• Device discovery and classification
• Trusted SSID, BSSID and gateway identity checks
• Evil Twin detection and alerts
• Device profiles, segmentation and quarantine workflows

Architecture explored
React + TypeScript dashboard, Android agent concept, and Linux/OpenWrt gateway agent concept; secure communication design using TLS 1.3 and Ed25519.

PROJECT_02 · PROTOTYPE / TESTING

Evil Twin Attack Defence

A defensive Wi-Fi security project under the B4DCYBER Sentinel direction. The prototype includes a React/TypeScript dashboard and a Windows network-scan workflow using the Windows WLAN command-line output to inspect nearby SSIDs and BSSIDs.

Prototype areas
• Wi-Fi network visibility and scan workflow
• Dashboard views and alert presentation
• Simulation Lab for demonstrating suspicious access-point scenarios

Validation note
Some dashboard alerts and scenarios have used mock/simulation data. End-to-end detection against real rogue access points and supported Wi-Fi hardware has not yet been confirmed.
